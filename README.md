# Night Deck Pro

> 將 iPhone 化身為隨身 DJ 控台。  
> Turn your iPhone into a portable DJ console.

Night Deck Pro 是一款以雙唱盤混音為核心的 iOS 音樂互動 App。使用者可以載入兩首歌曲，控制播放速度、節拍、EQ、音效與轉場，透過直覺化的手機介面體驗 DJ 現場演出的流程。

Night Deck Pro is an interactive iOS music app built around a dual-deck mixing experience. Users can load two tracks, adjust tempo, beats, EQ, effects, and transitions, and experience the workflow of a live DJ performance through an intuitive mobile interface.

## 中文介紹

### 專案特色

- **雙唱盤控制**：使用 Deck A 與 Deck B 同時播放及控制兩首歌曲。
- **節拍與速度調整**：透過 Pitch 微調播放速度，或使用 BPM Sync 快速同步節拍。
- **平順歌曲轉場**：使用 Crossfader 控制左右聲道比例，完成自然的歌曲銜接。
- **三段式 EQ**：分別調整高頻、中頻與低頻，避免兩首歌曲的聲音互相衝突。
- **音量與音色控制**：提供 Gain、Filter 與 Reverb，讓使用者即時塑造聲音層次。
- **快捷 DJ 效果**：整合 Hot Cue、Loop、FX Boost、Bass Drop、Echo、Cut Mute、Sync BPM 與 Reset Cue。
- **歌曲資料庫**：可從 Track Library 選取歌曲並載入不同唱盤。
- **新手混音引導**：透過預設混音技巧與一鍵操作，協助初學者理解常見的 DJ 轉場方式。
- **霓虹視覺設計**：深色介面搭配藍紅雙色，清楚區分兩個唱盤與控制區域。

### 基本玩法

1. 從 Track Library 選擇兩首歌曲，分別載入 Deck A 與 Deck B。
2. 播放第一首歌曲，將它設為目前的主聲道。
3. 在另一個唱盤設定播放位置，使用 Pitch 或 BPM Sync 對齊兩首歌曲的節拍。
4. 使用三段式 EQ、Gain、Filter 與 Reverb 調整下一首歌曲的音色。
5. 在合適的節拍點播放第二首歌曲，慢慢移動 Crossfader 完成轉場。
6. 加入 Loop、Echo、Bass Drop、FX Boost 或 Cut Mute，製造節奏變化與高潮。
7. 載入下一首歌曲並重複操作，完成一段連續的 DJ Set。

### 進階挑戰

- **手動對拍**：不使用自動同步，只透過 Pitch 讓兩首歌曲保持相同節奏。
- **無痕轉場**：利用 EQ 與 Crossfader，讓聽眾不易察覺歌曲切換的瞬間。
- **高潮編排**：運用 Loop、Filter 與 Echo 累積張力，再以 Bass Drop 或 FX Boost 進入高潮。
- **效果連段**：組合 Hot Cue、Loop、Cut Mute 與 Echo，創造個人化節奏表演。
- **自由混音**：自行安排曲序、轉場方式與效果，製作獨一無二的 DJ 演出。

### 適合對象

Night Deck Pro 適合喜愛電子音樂、節奏互動、DJ 文化與音樂創作的使用者。即使沒有專業 DJ 設備或混音經驗，也可以從直覺化介面與快捷功能開始，逐步練習節拍判斷、音色控制與現場編排。

## English

### Key Features

- **Dual-deck control:** Play and control two tracks simultaneously with Deck A and Deck B.
- **Tempo and beat adjustment:** Fine-tune playback speed with Pitch or quickly align tracks using BPM Sync.
- **Smooth transitions:** Blend audio between both decks with the Crossfader.
- **Three-band EQ:** Adjust high, mid, and low frequencies independently for cleaner mixes.
- **Sound shaping tools:** Use Gain, Filter, and Reverb to shape the sound in real time.
- **Instant DJ effects:** Access Hot Cue, Loop, FX Boost, Bass Drop, Echo, Cut Mute, Sync BPM, and Reset Cue controls.
- **Track Library:** Browse and load songs into either deck.
- **Beginner-friendly guidance:** Learn common DJ transitions through preset mixing techniques and one-tap actions.
- **Neon interface:** A dark UI with blue and red accents clearly separates both decks and their controls.

### How to Play

1. Choose two songs from the Track Library and load them into Deck A and Deck B.
2. Start the first track and use it as the active deck.
3. Set the starting point of the next track, then align both tracks with Pitch or BPM Sync.
4. Adjust the incoming track with the three-band EQ, Gain, Filter, and Reverb controls.
5. Start the second track on beat and gradually move the Crossfader to complete the transition.
6. Add Loop, Echo, Bass Drop, FX Boost, or Cut Mute effects to create rhythmic changes and build excitement.
7. Load another track into the inactive deck and repeat the process to create a continuous DJ set.

### Advanced Challenges

- **Manual beatmatching:** Match both tracks using Pitch without automatic synchronization.
- **Seamless transitions:** Use EQ and the Crossfader to make track changes nearly unnoticeable.
- **Energy building:** Combine Loop, Filter, and Echo before triggering Bass Drop or FX Boost at the climax.
- **Effect combos:** Chain Hot Cue, Loop, Cut Mute, and Echo to create original rhythmic performances.
- **Freestyle mixing:** Arrange tracks, transitions, and effects freely to produce a unique DJ set.

### Who Is It For?

Night Deck Pro is designed for users interested in electronic music, rhythm-based interaction, DJ culture, and music creation. No professional DJ equipment or previous mixing experience is required. Beginners can start with the intuitive controls and quick actions, then gradually develop their beatmatching, sound-shaping, and live arrangement skills.
